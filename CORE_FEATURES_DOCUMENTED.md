# Feature 3: 110% BT.2020 & 1000:1 Contrast

## Overview

The MoGo 4 supports a wide color gamut (110% BT.2020) and 1000:1 native contrast ratio, delivering cinematic color accuracy and deep blacks for a premium viewing experience.

## Technical Specifications

| Specification | Value |
|----------------|-------|
| Color Gamut | 110% BT.2020 |
| Contrast Ratio | 1000:1 (Native) |
| Color Standard | DCI-P3 90% |
| Display Technology | DLP |
| Display Chip | 0.23" DMD |

## What BT.2020 Means

BT.2020 (Rec. 2020) is an international standard for ultra-high-definition television. Achieving 110% coverage means the projector reproduces colors beyond the standard gamut, resulting in more vibrant reds, greens, and blues.

## What 1000:1 Contrast Means

A 1000:1 contrast ratio indicates that the brightest white is 1000 times brighter than the darkest black the projector can display. This creates:

- Deeper, richer blacks
- Better shadow detail
- More dimensional, lifelike images

## Use Cases

- **Movies & TV:** Cinematic experience with accurate skin tones and vivid scenery
- **Sports:** Clear visibility of fast-moving action and team colors
- **Gaming:** Immersive visuals with accurate color representation
- **Photo/Video Viewing:** True-to-life color reproduction

## User Benefits

- Professional-grade color accuracy
- Enhanced viewing immersion
- Support for HDR-compatible content
- Reduced color banding and artifacts

# Feature 7: Magnetic Creative Filter

## Overview

The MoGo 4 supports Magnetic Creative Filters—snap-on lens attachments that transform the projected image into ambient lighting effects. The Sunset filter is included in the box; additional filters (Lunar, Ripple, Dreamscape) are available separately.

## Technical Details

| Specification | Value |
|----------------|-------|
| Included Filter | Sunset (1× in box) |
| Additional Filters | Lunar, Ripple, Dreamscape (sold separately) |
| Attachment | Magnetic snap-on |
| Best Use | Ambient lighting, mood setting |
| Optimal Environment | Low-lit rooms |

## How It Works

1. Power on the projector in standard mode or Ambient Light mode
2. Snap the magnetic filter onto the lens
3. Project colored light or patterns onto walls/ceiling
4. Pair with Bluetooth music for synced ambiance

## Use Cases

- **Ambient Lighting:** Replace traditional lamps with projected light
- **Parties & Events:** Dynamic, colorful atmosphere
- **Relaxation:** Calming sunset or lunar effects
- **Music Visualization:** Lights respond to audio

## User Benefits

- Instant room transformation
- No additional hardware for basic effects
- Easy to swap filters
- Combines projector + speaker + ambient light
